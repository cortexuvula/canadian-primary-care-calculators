# Reproducible verification

All fixtures and screenshots use synthetic data. Numerical expected values in the independent vector fixtures are not calculated by the production code under test. The finite full-precision vectors use absolute tolerance ≤1e-9 (scores exact), supplemented by branch/boundary and deliberately unsupported cases. Passing a finite suite is not proof of correctness for all inputs or a clinical/regulatory certification.

The normalized expansion fixture contains 69 valid vectors and 25 guard cases for the twelve additions, in addition to the original models' tests. One raw HAS-BLED vector (`V6`) is explicitly quarantined: its score 1 contradicts age 70 (+1) plus hypertension (+1). It is never used as an expected result, and a test asserts this exact quarantine so exclusions cannot silently grow. `node scripts/normalize-doc-vectors.js` reproduces the normalized fixture and display vectors without importing the production engine. `python3 scripts/recompute-guard-pins.py` independently recomputes the original Framingham/eGFR regression pins from cited coefficients.

## Commands

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:browser:sdk
npm run test:mutations
hermes plugins validate . --install-deps
```

- Unit tests cover the engine, Canadian conversions, score branches, independent vectors, registries, state/privacy and catalog navigation.
- Build verifies runtime imports against the public SDK/React allowlist, checks `runtime.sha256`, and writes identical root and desktop copies. Source paths are preserved so esbuild emits the reviewed bytes independent of checkout location.
- Browser tests load **compiled plugin.js**, real React and a boundary adapter for SDK registration, storage, navigation and clipboard; they exercise 15 calculators, stale-result/error/focus/copy behaviour, both appearances and responsive layouts. Scale fixtures of 50/150/300 entries are fictional and are never registered in the production plugin.
- `test:browser:sdk` additionally replaces Button/Input adapters with checksum-pinned upstream v0.21.6 controls. Network access is used only to fetch the test fixture; runtime calculations remain offline and tests assert the runtime's no-transmission behaviour.
- Mutation tests require assertion failures for 44 deliberate numerical/guard/state defects in ignored isolated copies. Infrastructure failures do not count as detected mutations.
- Admission validation applies the stock security scanner, desktop-surface and no-core-override gates. A no-`__init__.py` capability-probe warning is expected for this desktop-only package; no fake backend is added to silence it. Static admission is not a live desktop load.

Generated diagnostic data/screenshots go under ignored `.artifacts/`; Playwright output goes under ignored `test-results/`. No historical internal logs or installation receipts are distributed. Public screenshots are selected synthetic examples regenerated by `e2e/public-screenshots.spec.js`.

## Unverified boundaries

The full Desktop loader, live sidebar mount, real host CSS/theme, actual operating-system clipboard, and platform-native installation/UI are **not exercised** by the browser harness. This preview makes no live-host, clinical, legal, regulatory or blanket accessibility certification. CI configuration is provided, but actual GitHub checks must pass at the published commit before a release/catalog submission is represented as ready.
