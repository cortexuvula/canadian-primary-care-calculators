# Synthetic screenshot provenance

Every public image is generated by `e2e/public-screenshots.spec.js` from the compiled plugin in the test harness. There are no patient identifiers, patient records, system desktop captures or incidental application windows. The BSA example uses synthetic height 170 cm and weight 70 kg. Blank library views contain no measurements. Harness screenshots do not establish real Desktop mounting or OS clipboard behaviour.

Regenerate after `npm ci && npm run build`:

```sh
npx playwright install chromium
npx playwright test e2e/public-screenshots.spec.js
```

Generated images first land in `.artifacts/public-screenshots/`. To deliberately refresh the public gallery, inspect those images, then copy the three named PNGs into `docs/screenshots/`. Browser/OS/font versions may change screenshot pixels; runtime and release ZIP reproduction do not depend on reproducing pixel-identical screenshots. Committed image bytes are included verbatim in release checksums.
