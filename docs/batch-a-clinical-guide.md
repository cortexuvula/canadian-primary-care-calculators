Version 0.4.0 preview adds only the following eleven requests, bringing the fixed library to **26 calculators in 15 discovery categories**. Other expansion requests remain deferred. This is an implementation contract summary, not a clinical/code approval or a claim of live-host certification. Full source links, input anchors, method, conversion, limits and qualified interpretations are available within each calculator.

## Exact urine conversion

Creatinine molecular weight **113.12 g/mol**: mmol/L ×113.12 = mg/L; mg/dL ×10/113.12 = mmol/L. Analyte mg/dL ×10 = mg/L. Ratio SI = analyte mg/L / creatinine mmol/L; conventional = analyte mg/L / creatinine mg/L ×1000. Exact bridge mg/g = mg/mmol ×1000/113.12; inverse **0.11312**. KDIGO rounded 0.113 and category approximations (3 mg/mmol ≈30 mg/g) are not arithmetic constants. Positive finite denominator and analyte required; over/underflow blocks.

## Independent oracle and adjudication

`tests/fixtures/doc-batch-a-vectors.json` retains Doc's **85 valid + 34 guard** cases, without numerical edits/exclusions/quarantine. Only `_meta.sourceBrief` is sanitized from a local filesystem path to a public document reference; the external original is untouched. `scripts/normalize-batch-a-vectors.js` generates display strings without importing production calculations. Choice values become strings; LR arrays become explicit numeric-list text. The harness deliberately adds `outputUnit: mg/mmol` (both full-precision ratio outputs are still asserted) and `independent: yes` to LR cases. These are **test-only explicit choices**, never UI defaults. Doc separately confirmed these normalizations and that gestational-domain bounds are engineering guards. Doc adjudicated fractional SpO₂ as a new integer-only guard; no existing oracle row changed. New branch tests preserve that decision.

## Privacy and qualification

Every form starts blank; no default clinical answers. Editing any field clears current result/copy synchronously. Reset, model switching and unmount discard drafts/results. Only known favourite IDs persist; inputs/results are never transmitted, logged, cached or placed in URLs. Copy is a deliberate OS-clipboard action and clipboard data may outlive reset. Tests exercise compiled plugin bytes with real React and both SDK adapters/pinned public controls, **not** the complete Desktop loader/theme/OS clipboard. Exact candidate review evidence is external to source; implementation alone is not approval to publish or install.
